# CONCEITO

- Funções são blocos de códigos que executam tarefas específicas
- Evita repetições
- Deixa o código mais limpo
- Usar a mesma função em vários projetos

# Definição (def)

- Use 'def nome_funcao()' para declarar uma função.
- Parâmetros "()": valores que a função recebe
- Return: A saída e o resultado

## Exemplo prático - Função com parâmetros

- def saudacao_personalizada(nome):
-  print(f'Olá, {nome}')
