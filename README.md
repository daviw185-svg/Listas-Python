# Listas-Python

- Ordenada - Os elementos têm posição definida
- Mutável - Pode ser alterada após criada
- Heterogênea - Pode misturar tipos de dados
- Dinâmica - Tamanho pode crescer ou diminuir

# Lista vazia
```
lista1 = []
lista2 list()
```

# Lista com elementos
```
frutas = ["maçã", "banana", "laranja"]
numeros = [1, 2, 3, 4, 5]
misturada [10, "Python", 3.14, True]
```
# Usando range()
```
pares = list(range(0, 10, 2)) # [0, 2, 4, 6, 8]
```
# Índices e acesso
PYTHON
Índices positivos (começam em 0):
```
frutas ["maçã", "banana", "laranja"]
#         0        1         2
print(frutas[0]) # maçã
print(frutas[1]) # banana
print(frutas [2]) # laranja
```
